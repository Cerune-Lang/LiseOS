# LiseOS

**LiseOS（リーサOS）** は、Ceruneエコシステムとともに育てる実験的なオペレーティングシステムのプロジェクトです。

> **Status: planning / bootstrap**  
> このリポジトリは立ち上げ段階です。起動可能なカーネル、シェル、ファイルシステム、アプリケーション実行環境は、まだ実装済みとは扱いません。

[English](README.en.md)

## 目標

- OSの起動、メモリ、例外・割り込み、入出力、プロセス／タスク管理を、小さな実装とテストで段階的に理解・構築する。
- 可能な範囲で内部状態と失敗を観測できるようにし、仕様・実装・動作確認を区別する。
- [Cerune](https://github.com/Cerune-Lang/Cerune)、[Cisa](https://github.com/Cerune-Lang/Cisa)、[Sashimi](https://github.com/Cerune-Lang/Sashimi)との連携を検討する。ただし、それらへの依存や対応済み機能を現時点で確約しない。

## 最初に決めること

実装経路は、検証可能な最小例を作ってから選びます。

| 候補 | 最初の到達点 | 注意点 |
| --- | --- | --- |
| **Cisa上のゲスト環境** | Cisaの仮想CPUで起動・入出力・停止を観測する | OSらしい保護や割り込みにはCisa側の拡張が必要。ホストOS上で動くエミュレータと区別する |
| **x86-64 / QEMU** | ブートローダー経由で最小カーネルを起動し、出力・停止を確認する | freestandingなビルド、起動規約、ABI、リンカ、割り込み等の整備が必要 |

どちらを最初の正式ターゲットにするかは未決定です。**Ceruneでカーネル全体を書けることも、現時点では未検証です。**

## 最初のマイルストーン（案）

1. **M0 — 起動対象と境界の決定:** ターゲット、ツールチェーン、実行・テスト方法を記録する。
2. **M1 — Boot / Hello / Halt:** 最小プログラムが起動し、識別可能な出力を残して安全に停止する。
3. **M2 — 例外とメモリ:** 選択したターゲットで、メモリ配置と失敗の挙動を確認する。
4. **M3 — OSとしての最小機能:** ターゲットに合わせ、割り込み・タスク・システムコール等から実装範囲を決める。

これらは**計画案**であり、完成済み機能ではありません。

## 開発方針

- 小さく作り、実際に動かして検証する。
- 「設計した」「実装した」「起動した」「テストした」を混同しない。
- エミュレータ上で動いたことを、そのまま実機対応や安全性の保証にしない。
- 実装方針は、最小の再現例・テスト・観測結果を根拠に更新する。
